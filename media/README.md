# Media

## intro.mp4 (optional cinematic intro)

Drop a file named `intro.mp4` in this folder and the full-screen video
intro at the top of the site activates automatically — no code changes.

If the file is absent, the section removes itself and the site starts at
the normal hero. Nothing breaks either way.

Recommended: 6-12 seconds, 1920x1080, H.264/MP4, under ~8 MB, and make
sure it reads well muted (it autoplays silently; visitors can tap for sound).
